# Airbnb Experiences Clone

Projeto inspirado na interface de experiências do Airbnb, desenvolvido com **React, JavaScript e CSS**.

A aplicação apresenta uma coleção de experiências em cards, organizados para oferecer uma interface visualmente clara e intuitiva.

## Funcionalidades

- Exibição de experiências em cards.
- Apresentação de imagens e descrições.
- Exibição de avaliações e localização.
- Apresentação de preços e informações de cada experiência.
- Renderização dinâmica de conteúdo utilizando dados e componentes reutilizáveis.

## Tecnologias utilizadas

- React
- JavaScript
- CSS

## Como executar o projeto

1. Clone o repositório:

   ```bash
   git clone https://github.com/lkiryu/airbnb-experiences-clone.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd airbnb-experiences-clone
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

4. Inicie o servidor de desenvolvimento:

   ```bash
   npm run dev
   ```

## Objetivo do projeto

O objetivo foi praticar a criação de interfaces com React, componentização, reutilização de código e renderização de elementos a partir de dados, desenvolvendo uma página inspirada em um produto real.
